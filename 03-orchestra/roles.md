# Orchestra Roles

## Core Roles

| Musical Role | OrchestraX Role | Primary Function |
|---|---|---|
| Composer / Sponsor | Executive Sponsor | Defines desired business outcome |
| Conductor | GRC / Project Lead | Coordinates the complete system |
| Section Leader | Functional Lead / Control Owner | Coordinates a functional area |
| Musician | Specialist / Contributor | Performs assigned work |
| Soloist | Specialist SME | Performs a specialized responsibility |
| Score | Requirements / Policies / Controls | Defines what must be achieved |
| Rehearsal | Implementation / Testing | Validates readiness |
| Performance | Audit / Management Review | Demonstrates whether the system works |
| Audience | Management / Client / Auditor | Evaluates the result |

## Conductor Responsibilities

The GRC/project conductor is responsible for:

- Translating objectives into coordinated work
- Maintaining the project structure
- Making dependencies visible
- Coordinating stakeholders
- Tracking risks, issues, and decisions
- Challenging unclear ownership
- Monitoring evidence readiness
- Escalating blockers
- Maintaining alignment between requirements and implementation
- Preparing the system for assurance activities

## Conductor Is Not Responsible For

The conductor does not automatically:

- Configure every system
- Investigate every incident
- Approve every HR process
- Interpret every law
- Perform every vulnerability remediation
- Write every policy
- Produce every piece of evidence

## Specialist Responsibility

A specialist owns the technical or functional correctness of their area.

Example:

**MFA implementation**

- GRC/PM: coordinates requirement, owner, timeline, evidence and validation.
- IT/Security: selects and implements the technical solution.
- Control Owner: operates and maintains the control.
- Internal Audit: tests whether the control is designed and operating effectively.

## Capability Shift

The project uses this progression:

**Pianist → Four Hands → Section Leader → Conductor**

Each stage increases the scope of responsibility without requiring the person to personally perform every specialist task.

## Diagnostic Question

When something is not working, determine whether the underlying problem is:

1. Capability
2. Ownership
3. Dependency
4. Communication
5. Coordination
6. Resources
7. Requirement clarity
8. Control design
